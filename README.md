# consplus-direct

Прямое чтение баз КонсультантПлюс без оболочки: индексация, поисковое API и MCP-сервер
для ИИ-агентов. Работает поверх оригинальных файлов базы (read-only), тексты не копируются.

Direct access to ConsultantPlus database files without the shell: indexing, search API,
and an MCP server for AI agents. Works on top of the original base files (read-only).

## Возможности

- Чтение формата напрямую: TLV-записи + zlib (без шифрования), все базы (132+)
- 21+ млн документов: заголовки, тексты (сборка страниц), статусы, редакции, связи
- Полнотекстовый поиск с русской морфологией (FTS5 + стемминг, BM25), median 0.2 с
- REST API (FastAPI, Swagger) + MCP-сервер (stdio) для ИИ-агентов
- Шаблон opencode-агента "Mike": только проверенные источники, документы docx

## Quickstart (Windows)

Откройте PowerShell в папке проекта:

```powershell
scripts\setup.ps1                          # venv + зависимости
$env:CONSPLUS_BASES = "D:\путь\к\ConsultantPlus\BASE"
scripts\index_all.ps1                      # индексация ~2-3 часа (все базы)
scripts\merge.ps1                          # мерж + связи
scripts\run_api.ps1                        # API: http://127.0.0.1:8741/docs
python mcp_server\run.py                   # MCP stdio (API поднимется сам)
```

Частичная индексация одной базы: `python indexer\index_fast.py "BASE\LAW" index.db`

## Требования

- Windows, Python 3.13+, ~8+ ГБ RAM, SSD
- Локальная копия базы КонсультантПлюс (папка с `BASE\`)
- Диск: индекс ≈ 0.7 × объём базы

## Структура

| Папка | Содержимое |
|---|---|
| `consplus/` | библиотека чтения формата (TLV, zlib, INI, реквизиты) |
| `indexer/` | индексеры: fast, parallel (по группам), merge, relations |
| `api/` | FastAPI: поиск, карточки, тексты, статусы, связи |
| `mcp_server/` | MCP-сервер (7 инструментов) + авто-подъём API |
| `tests/` | per_base_test.py (10 запросов × каждая база) |
| `docs/` | формат, установка, устранение неполадок |
| `opencode-agent/` | шаблон opencode-проекта с агентом Mike |

## Переменные окружения

| Переменная | Назначение | Дефолт |
|---|---|---|
| `CONSPLUS_BASES` | путь к папке `BASE\` КонсультантПлюс | (требуется) |
| `CONSPLUS_API` | URL Search API | `http://127.0.0.1:8741` |
| `CONSPLUS_PORT` | порт API | `8741` |
| `CONSPLUS_INDEX` | путь к index.db | `./index.db` |
| `CONSPLUS_PARTS_DIR` | папка с index_part1..3.db | папка `CONSPLUS_INDEX` |

Поиск в MCP принимает `page` и `limit` (до 50 карточек на странице). Порядок
определяется рангом FTS и стабилен при изменении `limit`; высокий ранг сам по себе
не подтверждает, что найдена нужная редакция акта. Статусы и связи извлекаются
из аннотаций заголовков, в ответе по связям сохраняется исходная аннотация.
Поиск по реквизитам показывает начало текста каждой записи и поднимает выше
те, где номер и дата стоят в первых 120 символах. Это помогает отделить текст
акта от обзора или письма, но не определяет действующую редакцию.
`get_document_text` без дополнительных параметров возвращает полный текст;
`offset` и `max_chars` позволяют читать его фрагментами до 20 000 символов.

## Агент Mike (opencode)

Шаблон в `opencode-agent/`: opencode-конфигурация только с consplus MCP,
агент Mike — юридический ассистент, который отвечает строго по источникам из базы
и сохраняет результат как структурированный .docx. См. `docs/INSTALL.md` раздел 6.
Перед запуском замените пример пути к `mcp_server/run.py` в конфигурации шаблона.
