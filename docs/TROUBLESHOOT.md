# TROUBLESHOOT.md

## API не поднимается / порт занят
`error while attempting to bind on address ('127.0.0.1', 8741)` — порт занят другим
экземпляром. Либо остановите его (`Get-Process python | ? {$_.CommandLine -match 'uvicorn'} | Stop-Process`),
либо смените порт: `uvicorn api.main:app --port 8742` + `set CONSPLUS_API=http://127.0.0.1:8742`.

## Индексер медленный
- Исключите папки базы и индекса из антивируса (Windows Defender замедляет mmap-чтение в разы)
- Запускайте `parallel.py run N` на разных группах баз параллельно (не более 3-4)
- Замер: `Get-Content index_part1.log -Tail 2` — темп ниже 200 стр/с = что-то мешает

## FTS пустой / поиск не находит
Известная ловушка: FTS5 contentless-таблицы нельзя мержить через `INSERT ... SELECT`
(поле tokens не читается обратно). Поэтому FTS живёт в `index_part1..3.db`, а не в
`index.db`. Не удаляйте файлы частей после merge.ps1.

## MCP не стартует из opencode
Проверьте вручную: `python mcp_server\run.py` — должен напечатать ничего и ждать (stdio).
Частая причина: неверный путь в `opencode.json` шаблона агента или не стартовал API
(смотрите `api_autostart.log`).

## В базе X пусто или мало документов
~30 микробаз (FK*, GR*, IP*, PSV*...) имеют по 1-30 документов — это норма
(служебные/редиректные записи). Поиск по ним идёт по первой странице (TINY_BASE_LIMIT).

## Большие документы (кодексы) «обрезаны»
Консолидированный текст кодексов в базе не хранится целиком — он собирается из
редакционных срезов по ~600 КБ. Наш индекс собирает страницы в документы
(consplus\paginate.py); если конкретный документ выглядит обрезанным — это срез
редакции, полный текст = несколько соседних документов (см. CONS++.md).

## Ошибка вида «desync» / «zlib error» при индексации
База имеет нестандартные записи (редко в старых/спец-базах). Скрипты из `poc/`
(hex.py, tag_histogram.py) помогут посмотреть структуру. Сообщите об issue с именем базы.
