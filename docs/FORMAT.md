# FORMAT.md — формат файлов баз КонсультантПлюс (по результатам реверса)

Документировано по результатам собственного разбора (см. журнал `docs/CONS++.md`).
Никакой официальной документации не существует.

## Общая структура записей

Все файлы данных — последовательности TLV-записей:

```
[u16 tag][u32 len][payload], len включает 6 байт заголовка
```

Сжатые данные — zlib-поток (магия `78 9C`), без шифрования. Перед zlib-потоком
обычно 2 байта (crc/флаги). Проверка валидности: `zlib.decompressobj` доходит до eof.

## Файлы одной базы (BASE\XXX\)

| Файл | Содержимое |
|---|---|
| `XXX.INI` | словарь полей базы (запись-контейнер 0x8065) |
| `XXX.HDT` | заголовок базы (6 записей по 30 байт; сборка, счётчики) |
| `XXX.DT1` | заголовки документов (реквизиты) |
| `XXX.DT2` | тексты документов (страницы) + изображения |
| `XXX.DT3` | оглавления/структуры документов (перечни статей) |
| `XXX.DT4` | аннотации/примечания |
| `XXX.DT5` | бинарные объекты |
| `XXX.NX1-5` | полнотекстовые индексы Консультанта (не используем — свой FTS) |
| `XXX.RX2-3` | словари («CONS+ DICT(HUGE)») |
| `XXX.KUB` | справочники типов связей/статусов («Consultant rubrics file», CP866) |

## INI (словарь полей)

- Запись 0x8065 (весь файл); тело: 15-байтовый заголовок (`"F2"`, сборка, напр. "362")
- TLV-записи: 0x66 — имя базы, 0x67 — профиль версии, 6 × 0x8069 — дескрипторы частей
- Поле = запись 0x8070: `[u16][вложенные TLV с офсета 2]`:
  - 0x74 't': `[tag:u8][?:u8][имя CP866\0]`
  - 0x76 'v': `[?:u16][внутреннее имя ASCII\0]` (COMMON_DOCNAME, COMMON_DATE и т.д.)
- Поля ссылок: 0x0e «Внутрибазовые ссылки», 0x5a «Ссылки», 0x98 BACK_REF — НЕ разобраны

## DT1 (заголовки)

- Каждый документ = запись 0x80EA: `[crc2][0x80EC метаданные][0x00F1: zlib-заголовок][0x00F1: флаги]`
- Заголовок (decompressed): нуль-терминированные строки CP866 + бинарный хвост
  (вид, номер с префиксом, название, источник, даты, аннотации статусов)
- Аннотации («утратил силу в связи с изданием ... N ...») — источник связей

## DT2 (тексты)

- Текст страницами ≤ ~64 КБ (zlib); страница = запись 0x0175 `[crc2][zlib]`
- Малые документы = контейнеры 0x00F1 (`[crc2][0x0173][0x0174][0x0175]`)
- Страницы больших документов = записи 0x80EA (обёртка: 0x80EC + f1(8)-маркеры + f1-контейнер)
- 0x0176 = таблица позиций (статей) внутри страницы: пары `[u16][u32 offset]`
- Изображения = записи 0x0180 (PNG/JPEG внутри zlib)
- Страницы одного документа идут подряд; новая единица = страница-шапка
  (uppercase орган/вид + «от <дата>») или маркер редакции/вставки
  («|26 января 1996 года N 14-ФЗ\n|---»)
- Консолидированный текст кодексов целиком НЕ хранится — редакционные срезы (~600 КБ)

## Кодировки

CP866 — тексты и поля; CP1251 — отдельные строки движка. Русская морфология
для поиска строится своим индексом (FTS5 + snowball-стемминг).
